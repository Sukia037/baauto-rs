BAauto 測試

這個資料夾是給幫忙測試的人用的，平常玩遊戲用不到。
receiver-test 資料夾裡的程式是測試專用版，不要拿來玩遊戲。
兩個測試都不需要開遊戲。

1-latency-test.bat（延遲測試，約 2 分鐘）
  照畫面說明，反覆按 W、不時按住 2 再放開，大約 90 秒，時間到會自己結束。
  結束後這個資料夾會多出 result-1.zip。

2-receiver-test.bat（接收器自動測試，約 3 到 5 分鐘）
  程式會自己按鍵、點滑鼠、移動游標，逐項檢查每個功能送出的按鍵順序。
  也會檢查「按著按鍵時啟用」只會回到已停止，不會變成引擎故障。
  測試期間不要碰鍵盤和滑鼠，也不要切換視窗。
  結束後這個資料夾會多出 receiver-result-1.zip。

把產生的 zip 傳回來就好。
第一次雙擊 .bat 時 Windows 可能跳出安全性警告，確認是從 BAauto 的 Releases 頁面下載的，按「執行」。
