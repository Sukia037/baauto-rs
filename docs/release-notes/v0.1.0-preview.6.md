下載 `BAauto-v0.1.0-preview.6-windows-x64.zip`，解壓後執行 `baauto-app.exe`。完整使用說明見 README。

這一版是從 preview.4 重新修的，preview.5 的修改已經撤回。

## 這一版的變更（相對 preview.4）

- **長按左鍵點回遊戲不會再壞**：以前左鍵按久一點，引擎會拒絕啟用，接著被強制結束，變成「引擎故障」。現在右上角會顯示「等待啟用」，放開左鍵就自動變成「運作中」，不用再按一次「啟用」。
- **遊戲中的引擎故障**：
  - 你按住的熱鍵如果剛好是 BAauto 要送的鍵（例如按住 `2` 技能連點 1 時，技能連點 2 要送 `2`），以前會被誤判成「手和程式搶同一個鍵」而故障。熱鍵被 BAauto 攔下、不會傳到遊戲，現在不再算衝突。
  - 真的搶到同一個鍵時（例如普通點位按著左鍵，你又按了左鍵），以前會變成引擎故障；現在只是停下、放開 BAauto 送出的鍵，你放開後就自動繼續。「紀錄」分頁會寫是哪個鍵。
- **牌鍵多一個間隔「放開到回位」**：在點位上放開左鍵之後，游標停多久才移回你的位置。在「時間」分頁牌鍵那一列，範本是 16ms；舊的預設按鍵檔沒有這一格，讀進來是 0（和以前一樣），請自己調。

## 請幫忙測試

1. 在 BAauto 按「啟用」，然後**按住滑鼠左鍵點回遊戲**，按久一點再放開。應該先顯示「等待啟用」，放開後變成「運作中」，不會出現「引擎故障」。
2. 正常玩一段時間，包含同時按多個鍵。如果還是出現「引擎故障」，把 `logs` 資料夾壓縮傳回來；如果出現「等待啟用」，把「紀錄」分頁那一行（「… 被實際按住」）截圖回報。
3. 牌鍵：調「放開到回位」，看點擊是否都落在點位上。
4. 雙擊 `tests\2-receiver-test.bat`，跑完把 `receiver-result-1.zip` 傳回來。這次多了兩項：「按著按鍵時啟用」和「點位按著左鍵時又按左鍵」。測試期間不要碰鍵盤和滑鼠。

## 預覽版的限制

- 這一版的修改都只在 Mac 上做過自動測試和 Windows 編譯檢查，還沒在 Windows 實機跑過。
- 「時間」分頁的數值是範本值，還沒針對遊戲校準。
- 手牌校準的拖拉儲存、Windows 縮放 100／150／200%、真實舊設定檔匯入還沒逐項驗收。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能會跳出 SmartScreen 警告。

遇到問題請截圖，加一句「做了什麼、看到什麼」回報。
