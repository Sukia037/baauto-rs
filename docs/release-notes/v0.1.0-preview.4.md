下載 `BAauto-v0.1.0-preview.4-windows-x64.zip`，解壓後執行 `baauto-app.exe`。完整使用說明見 README。

## 這一版的變更（相對 preview.3）

- **時間設定重寫**：每個按鍵都是按下後馬上放開，可以調的是每一步之間的間隔。「時間」分頁改成一張表，每個功能一列，寫成 `Esc →〔16〕→ Esc`，括號裡的數字直接改。
- **開牌改成按一下跑完一次**：「Esc → 數字鍵 → 在游標位置點左鍵 → Esc」，按住不會重複出牌，放開也不影響。
- **按住熱鍵不再跟著鍵盤自動重複**：技能、暫停、AUTO、加速按住都只算一次。
- **牌鍵**：一輪是「數字鍵 → 移到點位按下左鍵 → 放開 → 游標回原位 → 下一輪」，時間在「時間」分頁的牌鍵那一列。
- **舊的預設按鍵檔照樣能開**：快／慢卡幀間隔、開牌前等待、點位維持週期沿用，其他換成新的預設值，「紀錄」分頁會列出換了哪些。
- **引擎故障會說原因**：一打開就顯示「引擎故障」時，「紀錄」分頁會寫「引擎意外結束：原因（結束代碼）」，例如被防毒軟體擋下或程式當掉；引擎的錯誤也會寫進 `logs\engine-error.txt`。
- **測試包合進同一個 zip**：`tests` 資料夾裡有延遲測試和接收器自動測試，雙擊 `.bat` 就能跑，跑完把產生的 zip 傳回來。

## 請幫忙測試

1. 雙擊 `baauto-app.exe`，確認不會多跳黑色視窗，按「啟用」後狀態變成「運作中」。如果顯示「引擎故障」，把「紀錄」分頁截圖回報。
2. 雙擊 `tests\2-receiver-test.bat`，跑完把 `receiver-result-1.zip` 傳回來。
3. 雙擊 `tests\1-latency-test.bat`，跑完把 `result-1.zip` 傳回來。
4. 在遊戲裡試開牌和牌鍵：開牌是否每按一次只出一張；牌鍵點擊是否點在點位上（不行的話，調大「時間」分頁牌鍵那一列中間的「按下到放開」）。

## 預覽版的限制

- 新的時間設定、開牌單次、測試包都只在 Mac 上做過自動測試和 Windows 編譯檢查，還沒在 Windows 實機跑過。
- 「時間」分頁的數值是範本值，還沒針對遊戲校準。
- 手牌校準的拖拉儲存、Windows 縮放 100／150／200%、真實舊設定檔匯入還沒逐項驗收。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能會跳出 SmartScreen 警告。

遇到問題請截圖，加一句「做了什麼、看到什麼」回報。
