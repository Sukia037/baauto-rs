下載 `BAauto-v0.1.0-preview.7-windows-x64.zip`，解壓後執行 `baauto-app.exe`。完整使用說明見 README。

這一版只修一個問題，其他內容和 preview.6 相同。preview.6 的變更見它的發佈說明。

## 這一版的變更（相對 preview.6）

- **「從舊檔／MuMu 匯入…」和「開啟」沒反應**：選好檔案後畫面完全沒變化，也沒有任何訊息。原因是讀檔完成的通知比「開始匯入／開啟」的通知晚到，介面還在忙，就把後面那一步丟掉了。這個問題從第一版就有，現在已修好。

## 請幫忙測試

1. 按「從舊檔／MuMu 匯入…」，選一個舊的 AHK 或 MuMu 點位檔。點位清單應該換成舊檔的點位。
2. 按「開啟」，選一個之前存的 BAauto 點位檔或按鍵檔，畫面應該換成那個檔的內容。
3. 存檔、另存之後重新開啟，確認內容一樣。
4. 如果還是沒反應，截圖整個視窗，並把 `logs` 資料夾壓縮傳回來。

## 預覽版的限制

- 這一版的修改只在 Mac 上做過自動測試和 Windows 編譯檢查，還沒在 Windows 實機跑過。
- 「時間」分頁的數值是範本值，還沒針對遊戲校準。
- 手牌校準的拖拉儲存、Windows 縮放 100／150／200%、真實舊設定檔匯入還沒逐項驗收。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能會跳出 SmartScreen 警告。

遇到問題請截圖，加一句「做了什麼、看到什麼」回報。
