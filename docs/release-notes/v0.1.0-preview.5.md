下載 `BAauto-v0.1.0-preview.5-windows-x64.zip`，解壓後執行 `baauto-app.exe`。完整使用說明見 README。

## 這一版的變更（相對 preview.4）

- **修正「啟用後一切回遊戲就引擎故障」**：切回遊戲的那一刻還按著滑鼠左鍵或 Alt 時，引擎會拒絕啟用。這本身沒錯，但接下來的停止沒被確認，監督程式等了 1 秒就強制結束引擎，畫面變成「引擎故障」。現在只會回到「已停止」，放開按鍵後再按一次「啟用」就好。
- **開不起來時會說原因**：以前雙擊沒反應就是沒反應。現在會跳出「BAauto 無法開啟」視窗寫出原因，同樣的內容存在 `logs\app-error.txt`。
- **直接在 zip 裡開啟會提醒**：找不到 `engine` 資料夾時，會說明要先「解壓縮全部」，或可能被防毒軟體刪掉。
- **AutoHotkey 同時執行時警告**：舊版 `BAauto.ahk` 等 AutoHotkey 腳本可能先攔走相同的熱鍵，讓 BAauto 進入故障。首頁會顯示紅色警告，但不擋啟用。

## 請幫忙測試

1. 在 BAauto 按「啟用」，然後**按住滑鼠左鍵點回遊戲視窗**。應該只會回到「已停止」，不會出現「引擎故障」；放開後再按一次「啟用」、切回遊戲，要變成「運作中」。
2. 正常切回遊戲（例如用工作列），確認會變成「運作中」，按鍵都有作用。
3. 開著 AutoHotkey 時打開 BAauto，首頁要出現紅色警告；結束 AutoHotkey 後約 3 秒內警告消失。
4. 雙擊 `tests\2-receiver-test.bat`，跑完把 `receiver-result-1.zip` 傳回來。這一版多檢查一項：按著按鍵時啟用，只會回到已停止、不會變成引擎故障（第 1 點的自動版）。
5. preview.4 的其他測試項目（延遲測試、開牌和牌鍵）還沒跑過的話，也請一起跑。

## 預覽版的限制

- 這一版的修改都只在 Mac 上做過自動測試和 Windows 編譯檢查，還沒在 Windows 實機跑過。
- Arm 被拒後不會自動重試，要再按一次「啟用」。
- 「時間」分頁的數值是範本值，還沒針對遊戲校準。
- 手牌校準的拖拉儲存、Windows 縮放 100／150／200%、真實舊設定檔匯入還沒逐項驗收。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能會跳出 SmartScreen 警告。
