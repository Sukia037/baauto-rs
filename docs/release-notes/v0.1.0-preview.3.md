下載 `BAauto-v0.1.0-preview.3-windows-x64.zip`，解壓後執行 `baauto-app.exe`。完整使用說明見 README。

## 這一版的變更（相對 preview.2）

- **引擎收進 `engine` 資料夾**：解壓後只看得到一個 exe，就是要開的 `baauto-app.exe`。從舊版更新時，把新的 `baauto-app.exe` 和 `engine` 資料夾一起放進原本的資料夾，舊的 `baauto-engine.exe` 可以刪掉，設定會保留。
- **直接雙擊引擎只會顯示提示**，告訴你改開 `baauto-app.exe`，不會再進入沒有緊急停止的開發用模式。
- **新增延遲測試包** `BAauto-latency-test-v0.1.0-preview.3-windows-x64.zip`：雙擊 `START.bat`，照畫面說明按約 90 秒，把產生的 `result-1.zip` 傳回來。不需要開遊戲。

## 這一版有什麼

- 23 個預設按鍵：技能、連點、卡幀開牌、普通暫停、快／慢卡幀暫停、AUTO、加速、滑鼠連點、緊急停止、錄製點位。
- 點位檔：普通點位（按住時游標移到該點並按住左鍵）和牌鍵。
- 牌鍵：按住熱鍵、滑鼠放在手牌上，會一直重複「送出游標所在那張牌的數字鍵 → 點一下牌鍵的位置 → 游標回到原處」。按住時可以換牌，不在手牌上時暫停。
- 六人／十人（制約解除決戰）兩種模式，手牌左右位置與手牌校準。
- 從舊版 AHK 的點位 JSON、`function_keys.json`、MuMu 設定匯入；舊版的「拖曳至點位」會轉成牌鍵，拖曳終點變成牌鍵位置。
- 緊急停止鍵被其他程式佔用時，首頁會顯示紅色警告；改鍵存檔後立刻恢復，不用重開。
- 淺色／深色介面。

## 已驗證

- Windows 自動測試全部通過。
- Windows 接收器（假遊戲）實測：23 個預設功能、普通點位、六人／十人每一格、錄點與滑鼠側鍵擷取、慢卡幀送出完整兩組 Esc、首頁熱鍵警告。

## 預覽版的限制

- **牌鍵剛改成按住循環**，自動測試已通過，但還沒在 Windows 實機重跑接收器測試，也還沒在真實遊戲裡使用過。
- 「時間」分頁的數值是沿用舊版 AHK 的預設值，還沒針對遊戲校準。牌鍵點擊如果被算到牌上而不是點位上，請調大「牌鍵回位等待」。
- 手牌校準的拖拉儲存、Windows 縮放 100／150／200%、真實舊設定檔匯入還沒逐項驗收。
- 不跳命令列視窗的修正（preview.2）、引擎資料夾、延遲測試包都只做過編譯檢查，還沒在 Windows 上實際執行確認。
- 執行檔沒有數位簽章，第一次執行時 Windows 可能會跳出 SmartScreen 警告。
