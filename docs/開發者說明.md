# BAauto-rs 開發者說明

給開發者與 coding agent 看的狀態、文件索引與建置細節。一般使用說明見[根目錄 README](../README.md)。

Blue Archive PC 版輸入輔助工具的 Rust 重寫版，取代原本的 AutoHotkey 腳本 `BAauto.ahk`。M1–M6 的實作、可攜式測試與 Windows 原生短程補測已完成；目前仍有失敗項目，尚未通過完整驗收。

## 這一版的功能重點

- 牌鍵：按熱鍵時，游標在第幾張牌上就送那張牌的數字鍵。
- 六人／十人（制約解除決戰）兩種模式，寫在點位 JSON 裡，跟著點位檔切換。
- 手牌 UI 左右位置都支援，預設右邊；手牌位置和範圍校準一次，所有點位檔共用。
- 兩種 JSON，像原本一樣分開：點位 JSON（每個關卡一份：六人／十人＋點位和牌鍵）和預設按鍵 JSON（23 個預設按鍵＋時間，像原本的 function_keys.json），各自切換，都可以直接手改。

## 建置與啟動

Windows 安裝目前 Rust stable 與 Visual Studio C++ Build Tools 後，在 repo 執行：

```powershell
cargo build --release --locked --workspace
.\target\release\baauto-app.exe
```

引擎 `baauto-engine.exe` 放在 app 旁邊的 `engine\` 資料夾（release 的版面），或直接和 app 同一資料夾（`target\release` 的版面）；app 先找前者。直接雙擊引擎只會顯示提示，開發用的獨立模式要明確加 `--standalone`。首次啟動會建立兩種範本 JSON 和 `settings.json`，資料預設存在執行檔旁；可用 `--data-dir <資料夾>` 指定其他位置。每個點位／預設按鍵 JSON 仍可單獨放在任何路徑，透過開啟對話框或拖入加入分頁。介面預設保持停止，按「啟用」才開始。

不用遊戲也能試：在兩個PowerShell視窗依序啟動接收器與app，再切到接收器測試輸入。

```powershell
# 第一個視窗：假遊戲接收器，正常關閉後保留CSV與同名JSON。
.\target\release\baauto-receiver.exe --hand six --side right --output receiver.csv
# 第二個視窗：控制介面。
.\target\release\baauto-app.exe --target-exe baauto-receiver.exe --data-dir C:\BAauto-test
```

若首頁頂部出現紅色的熱鍵佔用警告，點「前往「預設按鍵」改鍵」換一組沒被佔用的鍵盤組合並儲存即可；逐項操作見[Windows試跑清單](windows-試跑.md)。

macOS／Linux 可查看離線介面：

```sh
cargo build -p baauto-app
./target/debug/baauto-app --preview --data-dir /tmp/baauto-preview
```

離線預覽不會送出遊戲輸入。Windows 控制程序仍可使用 `--headless`；量測與校準工具見 [bench-howto](bench-howto.md)。

## 發布新版

Windows 執行檔由 GitHub Actions（`.github/workflows/release.yml`）在 `windows-latest` 上用 MSVC 建置，不在本機上傳。

1. 確認 `cargo fmt --check`、`cargo clippy`、`cargo test` 通過；需要時更新 `Cargo.toml` 的 `workspace.package.version`。
2. 寫好 `docs/release-notes/<tag>.md`（例如 `v0.1.0-preview.1.md`），一起提交。
3. 打標籤並推上去：
   ```sh
   git tag v0.1.0-preview.1
   git push origin v0.1.0-preview.1
   ```
4. Actions 執行 `cargo build --release --locked --workspace`，另外在 `target/kit` 用 `--features test-hooks` 建一份測試版並編出 `windows_capture`、`windows_actions` 兩個測試執行檔，打包成一個 `BAauto-<tag>-windows-x64.zip`，附上 `.sha256`，建立 Release。標籤含 `-` 的會標成預覽版（pre-release）。zip 內容：
   - `baauto-app.exe`、`engine\baauto-engine.exe`、`README.md`：正式版，不含 `test-hooks`、`fault-injection`、`bench-experiments`。
   - `tests\1-latency-test.bat`：執行 `tools\baauto-bench.exe quick`，用正式版引擎量 90 秒，結果壓成 `tests\result-N.zip`。
   - `tests\2-receiver-test.bat`：執行 `tools\baauto-bench.exe receiver-test`，用 `receiver-test\` 裡的 test-hooks 版 app／engine／receiver 跑兩個接收器測試（`BAAUTO_TEST_BIN` 指向該資料夾，緊急停止／錄點改用 `Ctrl+Alt+F12`／`Ctrl+Alt+F11`），證據和紀錄壓成 `tests\receiver-result-N.zip`。
   - 測試包的來源在 `tools/test-kit/`。
